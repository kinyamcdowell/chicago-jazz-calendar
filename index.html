How to subscribe

Copy the link for the calendar you want and add it to your calendar app as a subscription (not a one-time import). New events are picked up automatically each week.

  1. Google Calendar: Settings → Add calendar → From URL → paste the link. (Google refreshes ~every 12–24 hrs.)
  2. Apple Calendar: File → New Calendar Subscription → paste the link.
  3. Outlook: Add calendar → Subscribe from web → paste the link.
